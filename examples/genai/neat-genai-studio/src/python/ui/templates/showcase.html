The runtime · LLiMa

Real-time edge GenAI, under 10W. Built for you.

LLiMa is SiMa.ai's automated code-generation framework for LLMs and VLMs. Import a model from Hugging Face and LLiMa configures, quantizes, optimizes memory & compute, compiles and packages it — generating the binaries and Python orchestration to run directly on Modalix. A unified on-device framework with zero cloud dependency.

01 · IMPORT

Any model

Open-source or custom LLM/VLM from the curated zoo or Hugging Face.

02 · OPTIMIZE

Auto quantize

Quantization, memory & compute tuned automatically for the MLA.

03 · COMPILE

Package for edge

Deterministic binary/ELF files + a Python orchestration script.

04 · RUN

On Modalix

Seamless, performant execution on-device — no hand-tuning.

The SDK · Palette Neat

This studio was built with Palette Neat.

Neat is SiMa.ai's software suite for teams building production AI applications at the edge. It keeps model packages, application composition and runtime execution as separate concerns, so you build and validate close to the target — and reuse tested patterns instead of hand-maintaining brittle pipelines.

Neat GenAI Studio is the proof point: a complete, deployable app assembled on Neat + LLiMa — not a slideware demo.

Compose

Model, app & runtime, decoupled

Swap models at runtime without touching the app; the same composition runs the same everywhere.

Validate

Build close to the target

Reuse

Tested patterns, not glue code

From board to chat in three commands

Bring GenAI to the real world.

Fetch the example, run setup, and you're chatting with an on-device model in minutes — the premier out-of-the-box edge-GenAI experience, ready to demo, benchmark and hand to a customer.

# fetch this example onto your Modalix
$ curl -fsSL https://raw.githubusercontent.com/sima-neat/apps/main/scripts/get-example.sh | bash -s -- neat-genai-studio
# install everything + create the neat-ai alias
$ cd neat-genai-studio && ./setup.sh
# start the studio — or neat-ai --cli for the terminal client
$ neat-ai
